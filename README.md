## ✨ Features

- 🐣 **Digital Pet** - Feed, play, and care for your pixel companion
- 🎮 **Mini Games** - Classic Snake game with retro vibes
- 📱 **PWA Ready** - Install on iOS/Android like a native app
- 💾 **Persistent State** - Your pet remembers everything
- 📳 **Haptic Feedback** - Feel every interaction
- 🌙 **Day/Night Cycle** - Room changes from day to night
- 📈 **Level System** - Watch PixelPal grow from baby to adult
- 🎨 **Y2K Aesthetic** - Neon colors and retro vibes

## 🚀 Quick Start

### Install as App

**iOS:**
1. Open in Safari
2. Share → "Add to Home Screen"
3. Enjoy! 🎉

**Android:**
1. Open in Chrome
2. Menu → "Install app"
